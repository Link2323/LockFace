LockFace 人脸识别隐私说明与知情同意书

版本：1.1
生效日期：2026 年 10 月 27 日
适用软件：LockFace 1.9.1 及后续版本（包括安装程序、LockFaceService、LockFaceCredentialProvider、LockFaceConsole 及相关组件）

特别提示：用于身份识别的人脸信息属于敏感个人信息或适用法律下的特殊类别个人数据，请在录入前阅读并确认。安装时确认阅读，注册时另行授权本人的人脸处理；授权范围见第六条，删除和撤回方式见第七条。

第一条 软件与处理主体

1.1 “本软件”：指由 LockFace 开源项目发布的人脸识别登录软件及其各个组件。
1.2 “项目方”或“我们”：指 LockFace 开源项目的维护者，项目地址为 https://github.com/Link2323/LockFace。
1.3 “你”：指安装或使用本软件的自然人。
1.4 “人脸信息”：指以电子或者其他方式记录的与已识别或者可识别的自然人有关的面部特征生物识别信息。本软件从摄像头画面中提取并保存的人脸特征向量，称为“人脸模板”。
1.5 “本地处理”：指在本软件运行所在的计算机上完成，不将数据传输至项目方或者任何第三方的处理活动。
1.6 我们提供本地运行的人脸登录软件。软件根据你的授权，在本机采集人脸画面、提取和保存模板，并在登录验证时读取、比对模板及使用对应的登录凭据。我们不提供人脸识别云服务；软件不会将上述人脸信息回传至项目方服务器，也不通过网络向我们开放本机人脸数据库。你主动提交的问题反馈另见第 8.2 条。
1.7 本机数据的管理与实际使用场景有关。自行使用时，由你管理设备及本机录入；企业、学校或其他组织为他人部署时，由实际决定处理目的和方式的主体履行相应管理义务。处理者或控制者责任、个人或家庭事务例外等法律规则，按适用法律和具体用途确定。组织部署的要求见第十条。

第二条 处理目的与必要性

2.1 本软件处理人脸信息，用于你选择的人脸登录功能：录入时生成或更新本地模板；解锁时，将摄像头画面中的人脸特征与本机已录入的各账户模板比较，结合最佳匹配、账户间区分条件及活体检测结果确定账户，验证通过后向 Windows 提交对应账户的登录凭据。
2.2 人脸登录是可选的身份验证方式，并非唯一验证方式。人脸模板用于识别身份，账户标识用于关联模板与账户，保存的加密密码用于在识别通过后完成 Windows 登录。你可以不录入人脸，继续使用密码或其他系统支持的登录方式。
2.3 本软件不将人脸信息用于广告、用户画像、信用评估、算法训练或者其他与登录验证无关的用途。
2.4 渐进式学习的设计用途是在人脸登录后，以该次画面的人脸特征小幅更新本机已有模板，不改变内置识别模型，不属于模型训练。当前版本暂不启用该功能，不会通过该功能自动更新模板。将来启用前，我们将更新相关说明，并在适用法律要求时另行取得有效授权。

第三条 处理的信息与摄像头启用

3.1 本软件在本地处理以下信息：
    （一）摄像头画面：在人脸登录验证、注册预览和采集期间获取，按阶段需要在内存中用于实时预览、人脸检测、对齐、活体检测和特征提取；预览画面在注册界面显示，相关帧在内存中短期缓存，不写入磁盘；
    （二）人脸特征向量：由模型计算得到的数值特征，当前版本为 128 个浮点数，用于与本地人脸模板比对；
    （三）活体检测结果及分数：用于判断画面是否来自真人；
    （四）账户标识：Windows 账户名、UPN、SID，用于将人脸模板与账户对应；
    （五）加密后的 Windows 密码：为在识别通过后完成登录而保存在本机，不以明文形式保存；具体加密方式见第 5.1 条；
    （六）运行日志：可能包含时间、组件、账户标识、识别距离、阈值和错误码等诊断信息，不包含人脸图像，不记录密码明文；
    （七）本地设置和授权记录：包括软件配置、显示偏好、摄像头曝光调节状态、说明版本、确认或同意时间及撤回处理中状态，用于运行软件、记住选择和完成撤回。这些记录不含人脸模板，但与账户关联时仍可能属于个人信息。

3.2 本软件不保存人脸照片、视频或者摄像头原始帧，不采集指纹、身份证件、位置、通讯录、短信或者其他与登录验证无关的个人信息。
3.3 人脸检测、特征提取、活体检测和比对均在本机完成。摄像头只在人脸登录验证或注册预览、采集期间启动。
3.4 你同意当前隐私说明且没有待完成的撤回时，注册界面可以自动启动预览，无需先点击“开始采集”；已有有效同意记录时，重新打开注册界面可恢复预览。撤回处理中不恢复注册预览、不允许重新同意或保存新的录入，具体见第七条。

第四条 存储地点与保存期限

4.1 人脸模板、账户标识和密码密文存储于本机配置的数据目录下的 data\users.dat，默认路径为 C:\Program Files\LockFace\data\users.dat。软件还可能生成本地数据库备份和写入临时文件。
4.2 为持续提供人脸登录，本软件保存已录入的人脸模板、账户标识和密码密文，直至删除最后一张人脸、清空账户、完成撤回或者卸载清理。保存以功能所需期间为限。当前软件不按闲置天数自动删除数据，也不自动识别离职、设备转交等情况；停止使用或处理目的结束时，请及时完成相应清理。
4.3 摄像头画面、未保存的采集样本及推理中间结果，按预览、采集和验证阶段临时保存在内存中，结束相应流程、停止预览、撤回或退出时释放相关缓存，不写入照片或视频文件。
4.4 运行日志以 14 天为窗口检查活动日志并轮转旧文件，在轮转或旧编码日志转换时清理超过窗口的归档。14 天是轮转检查窗口，实际清理随组件运行和日志写入执行；程序停用、文件占用或权限问题可能使部分日志保留更久。
4.5 数据库备份和临时文件按第 7.3 条清理；另有备份不延长已删除信息的使用期限。本地配置供持续使用，个人同意记录供版本核对，撤回标记供删除重试；授权记录的位置和清理分别见第 6.4 条与第 7.6 条。
4.6 删除和撤回以软件提示的执行结果为准。部署场景依法需要更短或固定保存期限、自动销毁或严格日志期限时，部署主体应安排相应管理与技术措施，并确认清理结果。

第五条 安全措施与识别风险

5.1 密码由 SYSTEM 服务使用 Windows DPAPI（用户范围）加密，绑定服务运行身份及本机。普通用户仅取得新版密码密文文件，不能直接以自身身份解密。
5.2 SYSTEM 服务还使用用户作用域 Windows DPAPI 加密保存人脸特征向量、账户标识、标签与角度参数。生产安装的数据目录仅允许 SYSTEM 和 Administrators 访问。模板仅在认证轮次或管理操作期间临时解密，结束后清理；注册向导通过服务取得账户元数据，不读取既有人脸模板。文件头仅保留格式、模型、账户数量及密文长度。
5.3 本软件还检查模型完整性，避免记录明文密码或完整人脸向量。密码保留独立加密层，仅在认证通过后解密。运行日志仍包含第三条第 3.1 条所述账户标识及诊断信息，不作为匿名数据处理。
5.4 活体检测可以降低照片、视频、屏幕回放、面具等攻击的成功率，但不能完全防止高质量面具、3D 打印、深度伪造、摄像头注入、驱动或操作系统被控制等攻击。
5.5 光照、遮挡、距离、角度、年龄变化、妆容、双胞胎或长相相似的人，可能导致识别失败（误拒）或者错误通过（误识）。
5.6 若攻击者取得提升后的管理员或 SYSTEM 权限，或能够离线访问系统盘，仍可能解密或窃取相关数据。设备被恶意软件入侵、被他人物理接触、账户权限被攻破或者你被胁迫时，也可能发生数据泄露或非授权登录。
5.7 本软件不承诺 100% 的识别率或安全性，无法保证绝对安全。人脸登录属于便利性功能，不应作为高安全场景（包括但不限于存放高度敏感数据、共享电脑、无人值守环境）的保护措施。识别失败时，请使用密码登录。

第六条 你的选择与人脸处理授权

6.1 是否安装、录入人脸和使用人脸登录，由你自主决定。拒绝或撤回人脸处理授权，不影响使用 Windows 密码登录；你也可以安装后不录入人脸。
6.2 我们将安装阅读确认与人脸处理授权分开。安装界面的勾选用于确认已阅读本说明；启用人脸录入前，须由人脸所属使用者在注册界面单独勾选授权。管理员或安装者的确认不代替他人授权，具体授权要求按适用法律执行。
6.3 注册界面的人脸处理授权限于以下事项：
    （一）本人知悉人脸信息属于敏感个人信息，识别存在误识、误拒及被攻击风险；
    （二）本人明确同意在本机通过摄像头采集本人的人脸画面、提取和保存模板，并结合账户标识及加密密码，用于本人的人脸登录验证；保存规则见第四条；
    （三）本人知悉可以拒绝或撤回并继续使用密码登录，删除与撤回方式及完成条件见第七条；
    （四）本人在了解本说明所述处理方式、保存规则、安全措施和风险后，自愿、明确作出上述授权；授权仅用于本人的人脸登录处理。

6.4 安装阅读确认的版本和时间保存在本机 HKLM\SOFTWARE\LockFace；每个 Windows 用户的人脸处理同意版本和时间分别保存在 HKCU\SOFTWARE\LockFace，两类记录分别管理。发起撤回时另行记录待处理状态，以便中断或重启后继续删除。这些记录用于版本核对、记录授权选择和完成撤回，不含人脸模板，与账户关联时仍可能属于个人信息。本地版本和时间记录不提供经过认证的身份或电子签名证明；依法另有授权形式要求的，应同时满足相应要求。
6.5 首次录入时同意后，本软件会按 Windows 用户记住授权。该授权覆盖第 6.3 条所述范围内后续的预览、采集、模板保存和人脸登录验证，无需每次打开软件、录入或登录时重复勾选，你也可以随时撤回。重新进入注册界面时，如本说明版本发生变化，或同意记录丢失、无法读取，则需重新确认；有待完成的撤回时，应先按第七条完成撤回。不同 Windows 用户须分别授权。

第七条 查阅、更正、删除与撤回

7.1 本软件通过注册向导提供本机人脸管理功能：查看已录入记录的张数与名称、删除单张或全部人脸，以及通过重新录入更正模板。你可以依照本说明了解、选择、限制或拒绝相关处理；如需行使其他权利，可以通过项目 Issue 联系项目方。
7.2 删除最后一张人脸或清空当前账户时，一并删除该账户保存的身份信息和密码密文。你也可以卸载本软件以停止使用人脸登录；卸载会删除软件管理的人脸数据、配置和日志，个别被占用的文件将在系统重启后删除。
7.3 删除、撤回、覆盖重录以及账户身份或密码更新时，软件清理其管理的旧数据库备份和中断写入产生的临时文件，以后生成的备份以更新后的数据库为准。上述删除为文件及记录的逻辑删除，无法保证物理介质不可恢复，也不能删除你或第三方另行复制的文件、系统备份或磁盘快照。
7.4 你可以点击注册界面的隐私同意状态，选择“撤回同意”。软件立即停止本次注册界面的摄像头和采集、清除尚未保存的采集样本，并请求本机服务删除当前账户全部人脸、身份信息和密码密文及清理旧备份。请求服务删除前，先在本用户的本地设置中持久保存“撤回处理中”状态；未能保存时会报错，且不发出服务删除请求。服务收到有效请求后，先在本机受保护数据目录持久记录带有账户 SID 的撤回待办，禁止该账户参与后续人脸认证，再执行删除；删除失败或重启不会解除该禁用。该服务待办不含人脸模板或密码。
7.5 只有服务确认删除且旧同意记录已清理后，撤回才完成并清除待处理状态；再次使用需重新同意并录入。服务不可用、文件被占用或清理步骤失败时，待处理状态跨重启保留，继续阻止注册预览、采集、重新同意和新的录入保存，并提供“重试撤回”；状态读取失败时也保持这些功能关闭。服务已持久接受的撤回会在服务启动及运行期间自动重试删除，无需注册界面保持打开；待办在删除及相关清理确认后移除。注册程序下次启动也会自动重试本用户未完成的撤回，并保留手动重试。服务无法连接、请求尚未送达或服务未能持久接受时，此前的人脸登录仍可能可用，请检查服务、权限和日志后重试；已交付 Windows 的登录凭据无法追回。撤回不影响撤回前基于同意已进行的处理活动的效力。
7.6 撤回完成后清除本用户的同意记录和待处理状态，但不会自动清除机器级安装确认或既有运行日志。卸载清理机器级记录、当前用户及当时已加载用户配置中的记录；未加载的用户配置或清理失败可能留下记录，需要管理员后续清理。
7.7 具备相应文件访问权限时，本机管理员可复制第 4.1 条所述数据库，取得本地加密数据副本。该文件包含本机已录入账户的加密模板、标识与密码密文，并非按单个使用者分离；复制文件不等于获得解密模板导出。解密依赖原计算机和 SYSTEM 保护材料，不保证系统重装后可恢复。副本由复制者管理，其清理边界见第 7.3 条。注册向导未设单独的模板导出按钮。
7.8 获取数据副本、数据可携带、限制处理、反对处理及投诉或司法救济等事项，按适用法律规定的范围、条件和程序办理。注册向导未设独立的处理限制开关。组织部署时，由实际处理主体安排其他适当程序，在法定期限内响应请求，并说明依法不能满足请求的理由。由于数据库保存在本机，我们无法从远端代为读取或删除其中的数据。

第八条 本地处理与对外提供

8.1 本软件的人脸采集、模板存储和识别比对在本机完成，不上传人脸信息，也不向项目方或任何第三方出售、共享、提供或公开人脸信息。软件不进行人脸信息的跨境传输，不包含广告、统计分析、用户追踪或人脸信息回传功能。
8.2 若你主动通过 GitHub Issues 等渠道向项目方提交日志或截图，请先删除或遮盖账户名、SID、人脸图像等个人信息；项目方仅将你主动提供的信息用于故障排查。公开 Issue 中的内容可能被任何人查看、复制，并由平台按其规则保存。不要提交密码、人脸模板或完整凭据数据库。
8.3 组织自行安排的数据复制、远程访问和备份，由相应组织管理。接收方、对外披露和跨境处理等事项，应按这些活动的实际情况履行适用义务；软件自身的本地处理方式不涵盖这些额外安排。

第九条 未成年人保护

9.1 未成年人的年龄标准、本人同意能力、监护人授权及其他保护要求，依适用法律和具体使用场景确定。为未成年人使用本软件前，应先确认当地适用的要求。
9.2 在中国境内，基于同意处理不满十四周岁未成年人人脸信息时，应取得父母或其他监护人同意，并制定专门的个人信息处理规则；其他地区依法执行当地要求。
9.3 当前软件未设置年龄核验、监护人身份及授权核验或专门的儿童注册流程。为未成年人部署人脸录入，应先具备适用法律要求的专门规则、有效授权和保护措施；安装者或未成年人的界面勾选不代替这些安排。发现不符合要求的录入时，应停止相关使用，并由依法有权的本人或监护人要求实际处理主体完成删除；本机删除方式见第七条。
