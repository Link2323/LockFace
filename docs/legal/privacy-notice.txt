LockFace 人脸识别隐私说明与知情同意书

版本：1.0
生效日期：2026 年 10 月 19 日
适用软件：LockFace 1.9.0 及后续版本（包括安装程序、LockFaceService、LockFaceCredentialProvider、LockFaceConsole 及相关组件）

特别提示：人脸信息属于敏感个人信息。请在安装本软件或录入人脸前，完整阅读本说明，特别是第七条关于风险提示与责任限制的内容。你勾选同意，即表示你已阅读并理解本说明的全部内容。

第一条 定义

1.1 “本软件”：指由 LockFace 开源项目发布的人脸识别登录软件及其各个组件。
1.2 “项目方”：指 LockFace 开源项目的维护者，项目地址为 https://github.com/Link2323/LockFace。
1.3 “你”：指安装或使用本软件的自然人。
1.4 “人脸信息”：指以电子或者其他方式记录的与已识别或者可识别的自然人有关的面部特征生物识别信息，包括本软件从摄像头画面中提取的人脸特征向量。
1.5 “本地处理”：指在本软件运行所在的计算机上完成，不将数据传输至项目方或者任何第三方的处理活动。

第二条 处理者与处理边界

2.1 本软件为本地运行的开源软件。项目方不运营人脸识别云服务，不设置用于接收人脸信息的服务器，不收集、不接收、不存储、不访问你的人脸信息。
2.2 人脸信息的处理活动均发生在你的设备上。你是否录入人脸、是否使用人脸登录，由你自主决定。
2.3 本软件不上传人脸信息，不向任何第三方出售、共享、提供或者公开你的人脸信息，亦不进行人脸信息的跨境传输。

第三条 处理目的与必要性

3.1 本软件处理人脸信息的目的仅限于：
    （一）在你发起人脸登录时，将摄像头画面中的人脸特征与你事先录入的人脸模板进行一对一比对，以验证是否为同一账户持有人，并在验证通过后完成 Windows 登录；
    （二）在你录入人脸时，生成或者更新本地人脸模板；
    （三）渐进式学习：在你完成一次人脸登录后，以该次画面的人脸特征对已录入的人脸模板做小幅自适应更新，以保持识别的准确度。该功能默认关闭，仅在本机进行，可以通过配置开启或者关闭。
3.2 人脸登录是本软件提供的可选身份验证方式，并非唯一验证方式。你可以不录入人脸，继续使用 Windows 密码或者其他系统支持的登录方式。本软件不会因你拒绝人脸识别而阻止你使用密码登录。
3.3 本软件仅在实现上述目的所必需的范围内处理人脸信息，不将人脸信息用于广告、用户画像、信用评估、算法训练或者其他与登录验证无关的用途。渐进式学习仅调整你自己设备上已录入的人脸模板数值，不改变软件内置的识别模型，不属于模型训练。

第四条 处理的信息种类与处理方式

4.1 本软件在本地处理以下信息：
    （一）摄像头画面：仅在你发起人脸登录或者开始人脸录入后采集，在内存中用于人脸检测、对齐、活体检测和特征提取，处理完成后即丢弃，不写入磁盘；
    （二）人脸特征向量：由模型计算得到的一组数值特征（当前版本为 128 个浮点数），用于与本地人脸模板比对；
    （三）活体检测结果：用于判断画面是否来自真人，以及相应的分数；
    （四）账户标识：Windows 账户名、UPN、SID，用于将人脸模板与账户对应；
    （五）加密后的 Windows 密码：为在识别通过后完成 Windows 登录，本软件需要在本机保存你的密码；该密码使用 Windows DPAPI 加密并绑定本机，不以明文形式保存；
    （六）运行日志：可能包含时间、组件、账户标识、识别距离、阈值和错误码等诊断信息，不包含人脸图像，不记录密码明文。
4.2 本软件不保存人脸照片、视频或者摄像头原始帧，不采集指纹、身份证件、位置、通讯录、短信或者其他与登录验证无关的个人信息。
4.3 人脸检测、特征提取、活体检测和比对均在本机完成。摄像头仅在你发起人脸登录或者录入人脸时启动；锁屏预载阶段不打开摄像头。

第五条 存储地点、期限与安全措施

5.1 人脸特征向量、账户标识和加密后的密码存储于本机 <安装目录>\data\users.dat，默认路径为 C:\Program Files\LockFace\data\users.dat。
5.2 密码使用 Windows DPAPI（机器范围）加密，密钥绑定本机；data 目录的访问权限仅授予 SYSTEM 和 Administrators。
5.3 人脸信息的保存期限为实现人脸登录验证目的所必需的最短时间，即保存至你主动删除、撤回同意或者卸载本软件之日止。
5.4 你可以在注册向导中删除单张人脸、清空某账户的人脸或者删除账户。卸载本软件将删除全部人脸数据、配置和日志；个别被占用的文件将在系统重启后删除。
5.5 本软件采取访问控制、加密存储、模型完整性校验、日志脱敏等合理安全措施。但任何技术措施均不能保证绝对安全，详见第七条。

第六条 对外提供与跨境传输

6.1 本软件不向项目方或者任何第三方提供你的人脸信息。
6.2 本软件不进行人脸信息的跨境传输。
6.3 本软件不包含广告、统计分析、用户追踪或者人脸信息回传功能。
6.4 若你主动通过 GitHub Issues 等渠道向项目方提交日志或者截图，请先删除或者遮盖账户名、SID、人脸图像等个人信息；项目方仅将你主动提供的信息用于故障排查。

第七条 风险提示与责任限制

7.1 活体检测可以降低照片、视频、屏幕回放、面具等攻击的成功率，但不能完全防止高质量面具、3D 打印、深度伪造、摄像头注入、驱动或者操作系统被控制等攻击。
7.2 光照、遮挡、距离、角度、年龄变化、妆容、双胞胎或者长相相似的人，可能导致识别失败（误拒）或者错误通过（误识）。
7.3 本机保存的加密密码依赖 Windows DPAPI 和目录权限保护。若攻击者取得管理员或者 SYSTEM 权限、能够以你的账户运行代码，或者直接物理接触设备，仍可能解密或者窃取相关数据。
7.4 若设备被恶意软件入侵、被他人物理接触、账户权限被攻破或者你被胁迫，仍可能发生人脸数据泄露或者非授权登录。
7.5 本软件不承诺 100% 的识别率或者安全性。人脸登录属于便利性功能，不应作为高安全场景（包括但不限于存放高度敏感数据、共享电脑、无人值守环境）的唯一保护措施。识别失败时，请使用密码登录。
7.6 本软件按 MIT 许可证“按现状”提供，项目方不对识别率、可用性或者安全性作出明示或者默示保证。本条不排除或者限制依照适用法律不得排除或者限制的责任。
